## 生图规格

| 项 | 要求 |
|---|---|
| 文件名 | 表里的 `文件名` 列，全小写、无空格（如 `kiwi.jpg`） |
| 尺寸 | 512×512，正方形 |
| 格式 | JPG |
| 风格 | 与已交付的 51 张一致：3D 可爱风、圆润、单主体居中 |
| 背景 | 干净的浅色/白色背景（App 内会圆角裁切或径向柔化） |
| 文字 | 画面里不要出现任何文字 |
| 动作词 | 画一个可爱角色在做这个动作（如 `sweep` 画小人拿扫帚） |
| 形容词 | 画能一眼看出该特征的物体（如 `heavy` 画举重物、`sticky` 画粘住的糖） |
