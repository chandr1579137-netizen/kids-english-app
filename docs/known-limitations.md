# 已知限制

这份清单记录「当前版本确实做不到 / 只在某些条件下成立」的地方，避免以后把限制当成 bug 排查。

## 1. 尚未真机验证

所有验证都是在 iOS 模拟器上完成（截图 + 单元测试）。以下三件事**只有真机能确认**：

- 音频播放：1158 条音频是否存在静音、错配、音量异常
- 录音与跟读：麦克风权限弹窗、录制效果、回放音量
- 真实性能：1259 张词图渲染、长列表滚动、视频类资源加载是否卡顿

真机验证清单建议：

1. 学习页连点 20 个词的喇叭，确认每个都有声音、发音与单词对应
2. 课文页点「跟读」，首次应弹麦克风权限；允许后录 3 秒回放
3. 单词卡页快速滑动 15 个主题，确认无明显掉帧
4. 锁屏/切后台再回来，确认进度与计时正常

## 2. 每日时长只统计前台

`studySecondsToday` 只在 App 处于前台时累加（回前台才继续计时）。切到后台不计时是**有意设计**，不是漏算。

跨天判断只发生在：App 回到前台、冷启动、以及前台每秒计时器检查到日期变化时。如果 App 整夜挂在后台，第二天回到前台会正确换天。

## 3. Dynamic Type 放大有上限

全站字号跟随系统「文字大小」，但**封顶 1.35 倍**（游戏内页封顶 1.15 倍）。原因是放大到系统最大档会把糖果卡片的圆角、两列网格、底栏高度挤坏。

系统弹窗（家长侧共享面板、键盘等）不受此上限影响，由系统自行缩放。

## 4. 游戏难度不是独立题库

「简单 / 标准」只是按词条的 `level` 字段过滤（简单 = level 1–2），并且带一个「简单词不足 20 个就回退全量」的兜底。没有按年龄分级的独立题目集。

## 5. 备份格式暂无版本迁移

导出 JSON 里有 `version: 1` 字段，但**目前没有迁移逻辑**：以后如果改字段，旧备份可能无法恢复。届时需要写迁移，或提醒用户重新导出。

## 6. L1–L6 课文是上游内容

只有 L7 的 8 篇课文由本项目重写（原内容偏哲学，不适合 5 岁）。L1–L6 共 82 篇保留上游原文，个别句子可能偏长，尚未逐篇改写。

## 7. 双份源码树

仓库里 `KidsEnglish/*.swift` 与 `KidsEnglish/KidsEnglish/*.swift` 是两份必须一致的源码（Xcode 工程只编译后者，前者是历史镜像）。CI 有两道一致性校验，改文件后需要手动/脚本同步：

```bash
python scripts/sync_duplicated_sources.py
```

## 8. 没有网络与云能力

App 不发任何网络请求：无账号、无云同步、无分析、无崩溃上报。进度只在本机，换机靠手动导出/导入。这是家庭自用的取舍。

## 9. CI 构建时间

云端构建 + 双模拟器截图约 15–20 分钟，未加缓存。单纯改文档也会触发完整构建。

## 10. 内容量的取舍

动作（83 词）与形容词（81 词）占全表约 1/3，比其他主题厚很多。已通过「每日计划跨主题交错」缓解（第 1 天就能覆盖 10 个主题），但没有拆分基础/进阶。
