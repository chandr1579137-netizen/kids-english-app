## 1. 孩子看到什么

五个页签：**今天 / 图画 / 说一说 / 儿歌 / 家长**。背单词、单词卡、巩固练习都收在家长页后面（切回正常模式才看得到）。
界面上只有大图、喇叭和会跳的按钮，所有提示都靠声音，孩子不识字也能自己玩。

| 页签 | 内容 |
|---|---|
| 今天 | Tom 头像 + 今天要学的 3 张图 + 一个大大的开始按钮；下面是这一周的贴纸。今天做完后按钮变成「再玩一次」 |
| 图画 | 词包墙（10 个包，每包一排星星表示学了几个）。点进去是这一包的大图，点哪张就念哪张，可以听这一包的儿歌 |
| 说一说 | 口语课 L1（和正常模式同一套） |
| 儿歌 | 10 首儿歌 |
| 家长 | 数学题门 → 家长中心 |

## 2. 「今天」怎么走（约 5–7 分钟）

| 步 | 做什么 | 依据 |
|---|---|---|
| 复习 | 今天到期的旧词，最多 4 个：听音选图 | 回想比反复听记得牢；逐渐拉长间隔对学龄前有效（`plan.md` 竞品调研 [13][14]） |
| 学新词 | 每天 3 个（家长可调 3–8）：一词一卡，大图 + 念两遍，话筒跳起来请孩子跟着说，说完放孩子自己的声音再表扬 | Gus on the Go、Khan Kids：不识字靠图和声音；跟读只鼓励不打分（`phrases-lesson-v1.md` §4） |
| 小游戏 | 听音选图 5 题：今天的新词每个至少考一次，其余从复习词补；同一个词不连着考 | Duolingo ABC / Lingokids：每课 5 分钟以内，学完马上用 |
| 贴纸 | 今天学的第一个新词做成今天的贴纸，一天一张 | Lingokids 星星换贴纸；ABCmouse 奖励有上限 |

- **听音选图**：一个大喇叭、三张大图（上二下一）。点对了：图放大、星星飞出、表扬，自动下一题。点错了：那张图轻轻晃一下、变淡，再念一遍，**不出现红色，也不出现「错」**。
- **复习间隔**：学会当天进第 0 格，明天复习；之后每次第一次就答对升一格，间隔是 1 → 2 → 4 → 7 → 14 → 30 天；答错回第 0 格，明天再来。
- **再玩一次**：今天做完后，只玩 5 题听音选图（从学过的词里出），不改复习进度，不再发贴纸。

## 3. 词包（`Resources/baby-path.json`）

10 包、68 个词，全部有平涂词图和 Aria 发音（单测逐个检查）：

家人 · 小动物 · 颜色 · 数字 1–5 · 吃的喝的 · 身体 · 我会做 · （锁）数字 6–10 · （锁）衣服 · （锁）天气

- 前 7 包一开始就开；锁着的 3 包等前面都学完，按顺序一个个开。家长中心可以「解锁全部词包」。
- 去掉了 PR #3 的「打招呼」包：hello / hi / bye / yes / no / I / you 的现成图是带英文字母的毛绒字母，不识字的孩子看不懂。问候语改由「说一说」L1 用整句教。
- mom / dad / grandma / grandpa 念的是口语叫法，配图用平涂的 mother / father / grandmother / grandfather。
- 出题时干扰项不出易混词（`Confusables`），两个选项也不会用同一张图。

## 4. 家长中心

新增「宝宝模式（4 岁）」一栏：
- 打开 / 关闭宝宝模式；
- 每天新学 3–8 个词；
- 解锁全部词包；
- 已学多少词、贴纸几张。

**默认值**：全新安装直接进宝宝模式；已经有学习进度的老用户保持原来的正常模式，家长可以在家长中心切换。

## 5. 进度与备份

- 新 key：`babyWords`（每个词的格子和下次复习日）、`babyStickers`（日期 → 贴纸词）、`babyNewPerDay`、`babyUnlockAll`、`babyMode`。
- 备份 JSON 加了可选字段 `babyWords`、`babyStickers`：旧备份照样能导入，而且不会清空本机的宝宝进度。
- 宝宝模式学会的词也计入「已学单词」。
- 「清除全部学习进度」会一起清掉宝宝进度。
