### D1 宝宝模式：做，P0

- 按 `plan.md` P0-3 执行：参照 PR #3 提交 `42b70b1` 的思路在 main 上重新实现，**不直接合并 PR #3**。
- 这是 P0 里唯一还没开工的一项。Qoder 免费期到 10/24 23:59，时间紧，按 P0-3 的验收标准做，不额外加范围。

### D2 字母音：加，P1

- 按 `plan.md` P1：s a t i p n → c k e h r m d → g o u l f b。
- TTS 很难读准单独的音：**先出一组样音给用户试听**，不行就改由家长自己录。样音通过前不写界面代码。
- 排在 P0（含 D1）之后。

### D3 数字图：保留数字卡

- 用户没有采纳「数东西」方案，数字 1–100 继续用现在的数字卡。
- `plan.md` P1 里的「数字 1–10 改成数东西的图（10 张）」**取消**，Muse 不用出这 10 张。
- 注意：这和 STYLE 规范里「图里不出现数字」有冲突。按用户决定，数字卡作为**例外**保留；其他主题的新图仍然遵守「No text, no letters, no numbers」。

### D4 日常口语版式：B 一句一卡

- 采用 PR #11 原型的版式 B：一页一句，大图约 55% 高，英文 + 中文，🎤 跟读和 ▶ 我的声音（复用 `Recorder`），顶部小圆点进度，最后一页星星庆祝。

### D5 iPad：不做

- 新功能只按 iPhone 设计和验收，不再拍 iPad 截图，也不为 iPad 调布局。PR #19 起就按这条执行。

- CI 里的 iPad 截图步骤如果一直拖慢构建或者容易失败，可以单独开一个小 PR 去掉。去掉之前先告诉产品经理。

### D6 宝宝模式保留 mom / dad

- 用户「不要用 dad，要用 father；不要用 mom，要用 mother」这句话，说的是「说一说」头像下面的名字。用户也确认过：句子里保留 Mom / Dad。

- 「说一说」的句子里也是 Mom / Dad，两边教的是同一个词。
- 配图仍用平涂的 mother / father / grandmother / grandfather，不用资源包里同名的旧 3D 图。
- 产品经理提出，用户已确认（原话：「可以，宝宝模式保留 mom / dad」）。
