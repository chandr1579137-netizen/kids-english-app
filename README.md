# 英语小伙伴 KidsEnglish

给 5 岁孩子用的儿童英语启蒙 iOS App（SwiftUI 原生），仅家庭内部自用，不上架 App Store。

## 内容来源与署名（Attribution）

本 App 的课文、单词、练习题与配套音频来自 GitHub 开源项目：

- **magic-english-buddy** by xckevin — https://github.com/xckevin/magic-english-buddy
- 协议：Creative Commons Attribution-NonCommercial-ShareAlike 4.0 (CC BY-NC-SA 4.0)
- 词典词源 seed 来自 skywind3000/ECDICT（MIT 协议）

使用方式符合原协议：署名、非商业用途、相同方式共享。课文封面插图为本项目 AI 生成，儿歌词曲为本项目原创。

## 构建

推送到 GitHub 后，Actions 会自动在云端 Mac 编译出未签名的 IPA（Actions 页面下载），
再用 Sideloadly + 自己的 Apple ID 签名安装到 iPhone。
